# Föreläsning: JS-ramverk

## Dagens föreläsning

Dagens föreläsning hade ingen powerpoint-presentation, istället gick vi tillsammans genom grunderna i _React_ genom att bygga en webbapplikation där användaren kunde söka filmer genom webb API:t _OMDB_. Nedan är länk till den kod som vi gick igenom på föreläsningen:

- [https://github.com/Tibbelit/react-demo-lecture](https://github.com/Tibbelit/react-demo-lecture)

Några fler koncept som kan vara bra att titta på är t.ex. `useContext`, något som vi inte han med på dagens föreläsning. En utökad version av dagens kod (med t.ex. `useContext` för att hantera favoritfilmer) hittar ni här:

- [https://github.com/Tibbelit/demo-app](https://github.com/Tibbelit/demo-app)

En **stark rekommendation** är att spana in [https://www.freecodecamp.org/learn/front-end-development-libraries-v9/](FreeCodeCamp -Front-End Development Libraries Certification) och genomföra delarna:

- React Fundamentals
- React State, Hooks and routing

Det kommer att ge er en väldigt bra grun till inlämningsuppgift 6, samt projektet.
